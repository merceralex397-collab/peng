# Peng design pack

This pack contains a complete product-design starting point for **Peng**, a lightweight local-first library for prompts, skills, plugins, MCP server definitions, and subagents.

## Files

- `Peng_Axiomatic_Design_Spec.md` — full axiomatic product and technical design specification.
- `Peng_GUI_Wireframe.html` — self-contained interactive GUI prototype; open it in a modern browser.
- `Peng_GUI_Wireframe_Preview.png` — static preview of the main library/editor view.
- `Peng_Bundle_1.0.schema.json` — JSON Schema for Peng 1.0 bundle documents.
- `Peng_Format_v1_Example.peng` — validated example portable bundle containing all five asset types.

## Prototype controls

The HTML prototype supports selecting assets, search and filters, favourites, content editing, typed Setup/Links/Notes tabs, creating an asset, import preview, dependency-aware export preview, theme switching, and keyboard shortcuts.

It is a design prototype only: browser state is intentionally temporary and import/export actions show the intended workflow rather than reading or writing the local filesystem.
